# KK_COOLER

Official website for **KK COOLER (operating commercially as K.K. Enterprises)** — a prominent air cooler manufacturing, wholesaling, and retail business located in Jodhpur, Rajasthan.

## Features
- **Dedicated Product Pages**: Separate technical specification pages for all 14 cooler models across Personal, Commercial, and Tower categories.
- **Deep Technical Specs**: Full coverage of 23 product parameters, dimensions, motor/pump details, tank capacities, and downloadable spec sheets.
- **Interactive Multi-Angle Gallery & Video Demo**: Front, Back, Side photo angles and high-definition video demonstration streamed via Cloudinary CDN.
- **Direct WhatsApp & Phone Integration**: Instant 1-click enquiry to `+91 9351359518` (Proprietor: Mr. Kamal Arora) with model details prefilled.
- **Factory & Store Location**: Plot No. 168 / Plot No. 19, Ambika Nagar / Aditya Nagar, Near Dali Bai Circle (Dali Bai Mandir), Masuria / Bhadu Market, Jodhpur, Rajasthan – 342001.

## Tech Stack
- **Framework**: React (Vite)
- **Routing**: React Router DOM v7
- **Styling**: Vanilla CSS with modern responsive design system
- **Media**: Cloudinary CDN for HD Video streaming
